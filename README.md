# Scrapbook Studio

MASTER DESIGN SYSTEM PROMPT — Playful "Scrapbook / Sticker" Style (for Lovable / AI website builder)

Apply this exact design system to EVERY page, section, and category on this website from now on. This is not a strict corporate/minimal style — it is a playful, energetic, hand-crafted "scrapbook" style where elements feel scattered, tilted, and pinned together like a mood board, while still being a professional, conversion-ready product website.

1. Overall Mood

Design like a modern, confident, slightly playful startup brand — bold, colorful, high-energy, but still clean and legible. Think: "a designer scattered photos and sticky notes on a table and made it look intentional." Avoid generic flat corporate templates — every section should feel custom-crafted and a little unexpected.

2. Typography

Use a bold, chunky, rounded sans-serif for all headlines — thick stroke weight, tight letter spacing, often uppercase or near-uppercase for maximum impact

Headlines must always include ONE (sometimes two) keyword visually called out differently from the rest of the sentence — using a solid color pill/box background behind just that word, or a bright contrasting color change. This highlighted-word technique is the signature move and must appear on every major headline across the site

Body/subtext: simpler, regular-weight, smaller, high readability, muted or white depending on background

Buttons and badges use the same bold rounded font family as headlines, in smaller uppercase or sentence case

3. Color & Section Blocking

Do NOT keep the whole site white. Alternate full-bleed bold color background sections (e.g. teal, purple, deep blue, lime green, dark charcoal) with clean white/light sections for breathing room

Each bold color section should feel like its own "scene" with a distinct background color, while staying within one cohesive brand palette (pick 2–3 vivid accent colors + 1 neutral dark + white, and reuse them consistently everywhere — don't invent new colors per page)

Use soft organic blob/wave shapes as subtle background texture within colored sections (large, low-contrast, rounded blob shapes behind the content)

4. Signature Technique: Tilted, Scattered Cards

Never place all cards/images in a perfectly straight, aligned grid. Rotate cards/photos/UI-screenshots at small random angles (roughly -8° to +8°) so they look naturally scattered, like items placed by hand on a table or pinned to a board

Add soft drop shadows under each tilted card to reinforce the "floating/layered" depth

This applies to: feature cards, testimonial cards, photo galleries, UI screenshots/mockups, and category showcases

5. Signature Technique: Connector Lines + Pins

When showing a row of items (categories, features, steps), connect them with a thin curved line running underneath/behind, and mark each connection point with a small pin, dot, or tag icon — like photos clipped to a string

Use this specifically for "browse categories" or "explore topics" style sections

6. Badges & Tags

Use small pill-shaped badges liberally: above headlines (e.g. "Best App for X", "Trusted by X"), as small floating tags scattered near the hero (each in a different accent color, slightly tilted), and as inline labels within sentences (bordered pill around a word, like "Tasks" "Wikis" "Goals" inline in a sentence)

Badges should have rounded-full (pill) shape, small bold text, and can sit at slight tilts for the scattered effect

7. Decorative Doodle Elements

Scatter small decorative shapes throughout empty space: asterisks (*), small stars, circles, squiggly lines, plus signs, dots — thin-stroke, single-color, low-opacity so they don't compete with content

Use these to fill negative space and add energy without adding real information

8. Buttons

Primary CTA: fully rounded pill shape, bold solid accent color fill, bold white or black text, soft shadow

Optional secondary style: black/dark pill button with white text for contrast sections

Occasionally use a thick black outline/border around a button or card for a playful "sticker/comic" pop (neo-brutalist accent) — use sparingly, not everywhere

Button copy short, punchy, action-first ("Try Free", "Get Started", "Explore More")

9. Illustration / Mascot (optional, use if brand fits)

A simple, friendly mascot character or hand-drawn-style illustration can appear in corners of key sections (e.g. peeking from behind a card) to add personality and warmth

If used, keep the mascot's color palette consistent with the site's accent colors

10. Photos & UI Mockups

Photos should be presented as tilted "polaroid" style cards with white borders/padding, OR as clean floating UI screenshots with shadows — never as plain full-width uncropped images

Product/app screenshots inside colored frames or laptop/device mockups add credibility to SaaS-style pages

11. Trust / Social Proof Strip

Include a horizontal row of partner/client logos in grayscale or muted tone so they recede compared to the vivid brand colors elsewhere

Precede with a short trust line ("Trusted by X+ users")

12. Layout Rhythm

Alternate colored full-bleed sections and white sections down the page for visual rhythm

Within each section: small pill eyebrow label → bold headline with one highlighted word → short supporting text → tilted card cluster or CTA

Keep generous padding around sections despite the busy/scattered elements — energy should come from the scattered cards/doodles, not from cramming content

13. Consistency Rule (most important)

Every page, category, and new section generated from now on must reuse the same 2–3 accent colors, the same chunky rounded font, the same tilted-card technique, the same highlighted-keyword headline pattern, and the same pill-badge/doodle decoration style described above — so the whole site feels like one unified, hand-crafted brand, not a mix of different templates.
